The Thesis

Every chain is public-by-default. Zcash proved the demand for privacy; StealthShield delivers the Zcash thesis cross-chain with a working Solana reference implementation built from real X25519/ed25519 cryptography.

Core Architecture

Stealth Derivation (X25519 ECDH)
Sender derives one-time PK_stealth = PK_spend + sha256(shared_secret‖index)·G. Only the recipient's viewing key can invert the shared secret. No sender↔recipient linkability.
1-Byte View-Tag Scanning
view_tag = sha256(shared_secret‖index)[0] prunes non-matches in ms with zero false positives — thousands of announcements scanned at one X25519 + one SHA-256 each.
Anchor Rust Registry
Verified on-chain at programs/solana_stealth_shield: register_meta_key, send_stealth_payment (CPI transfer_checked, works with SPL and Token-2022 via token_interface), sweep_stealth_funds.
Real Client Cryptography
src/services/stealthCrypto.ts uses audited @noble/curves X25519+ed25519. Verified round-trip: sender-derived address === recipient-recovered address, view tags match.
